# Resume Builder – Backend

A lightweight mock REST API built using JSON Server to provide data storage and API endpoints for the Resume Builder frontend application.

## Tech Stack

<p>
  <img src="https://skillicons.dev/icons?i=json,nodejs" />
</p>

- **API Server:** JSON Server
- **Runtime:** Node.js
- **Data Storage:** JSON file
- **API:** REST API

## Features

- Mock REST API endpoints
- JSON-based data storage
- Data retrieval and management
- Frontend API integration

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd resume-builder-backend
```

Install dependencies:

```bash
npm install
```

## Run the Server

```bash
npm start
```
